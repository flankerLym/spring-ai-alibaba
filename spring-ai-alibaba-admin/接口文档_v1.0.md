# Spring AI Alibaba Admin 开放 API 联调文档



## 1. 基础信息

Base URL：

```text
http(s)://{host}
```

所有 `/api/v1/**` 接口均使用 API Key：

```http
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

| 功能 | Method | Path |
|---|---|---|
| 分页查询应用 | POST | `/api/v1/apps` |
| Workflow 调用 | POST | `/api/v1/apps/workflow/completions` |
| Workflow 异步启动 | POST | `/api/v1/apps/workflow/async-completions` |
| Workflow 异步结果 | POST | `/api/v1/apps/workflow/async-results` |
| Workflow 停止 | POST | `/api/v1/apps/workflow/stop-completions` |

## 2. 分页查询应用

```http
POST /api/v1/apps
```

### 请求

至少传一个筛选条件。

```json
{
  "status": "published",
  "type": "workflow",
  "pageNum": 1,
  "pageSize": 20
}
```

| 字段 | 必填 | 说明 |
|---|---:|---|
| `appId` | 否 | 应用 ID，精确匹配 |
| `name` | 否 | 应用名称，模糊匹配 |
| `type` | 否 | `basic` / `workflow` |
| `status` | 否 | `draft` / `published` / `published_editing` |
| `pageNum` | 否 | 页码，默认 `1` |
| `pageSize` | 否 | 每页数量，默认 `20`，最大 `100` |

### 返回

```json
{
  "requestId": "req_xxx",
  "code": 200,
  "message": "success",
  "data": {
    "pageNum": 1,
    "pageSize": 20,
    "total": 2,
    "records": [
      {
        "appId": "2101945275265347585",
        "name": "示例工作流",
        "description": "示例",
        "type": "workflow",
        "status": "published",
        "publishedVersion": "3",
        "method": "POST",
        "api": "/api/v1/apps/workflow/completions",
        "asyncApi": "/api/v1/apps/workflow/async-completions",
        "contentType": "application/json",
        "inputSchema": [
          {
            "key": "query",
            "type": "String",
            "desc": "User query",
            "required": false,
            "source": "sys"
          },
          {
            "key": "order_no",
            "type": "String",
            "desc": "订单号",
            "required": true,
            "source": "user",
            "defaultValue": ""
          }
        ],
        "requestJson": {
          "appId": "2101945275265347585",
          "conversationId": "",
          "stream": false,
          "draft": false,
          "inputParams": [
            {
              "key": "query",
              "type": "String",
              "source": "sys",
              "value": "请输入用户问题"
            },
            {
              "key": "order_no",
              "type": "String",
              "source": "user",
              "value": ""
            }
          ]
        }
      }
    ]
  }
}
```

核心字段：

| 字段 | 说明 |
|---|---|
| `pageNum` | 当前页 |
| `pageSize` | 每页数量 |
| `total` | 符合条件的数据总数 |
| `records` | 当前页应用列表 |
| `appId` | 应用 ID |
| `type` | `basic` / `workflow` |
| `publishedVersion` | 已发布版本 |
| `api` | 同步调用地址 |
| `asyncApi` | Workflow 异步调用地址 |
| `inputSchema` | 应用调用参数定义 |
| `requestJson` | 调用请求模板 |
| `prologueText` | BASIC 应用开场白，有配置时返回 |
| `schemaError` | 已发布配置无法读取时返回 |

Workflow 自定义变量名以 `inputSchema[].key` 为准。  
例如工作流中定义为 `user_stage`，调用时仍传 `user_stage`，不修改变量名本身。

## 3. BASIC / Chat 调用

```http
POST /api/v1/apps/chat/completions
```

### 请求

```json
{
  "appId": "app_xxx",
  "conversationId": "",
  "stream": false,
  "messages": [
    {
      "role": "user",
      "contentType": "text",
      "content": "你好"
    }
  ],
  "promptVariables": {},
  "draft": false
}
```

| 字段 | 必填 | 说明 |
|---|---:|---|
| `appId` | 是 | BASIC 应用 ID |
| `conversationId` | 否 | 多轮会话时传上一次返回值 |
| `messages` | 是 | 消息列表 |
| `stream` | 否 | `false`：JSON；`true`：SSE |
| `promptVariables` | 否 | Prompt 变量 |
| `draft` | 否 | 外部调用固定 `false` |

### 返回

```json
{
  "conversationId": "conv_xxx",
  "status": "completed",
  "content": "你好，有什么可以帮助你？"
}
```

流式调用事件体字段相同，以 `status=completed` 或 `status=failed` 作为业务结束状态。

## 4. Workflow 调用

```http
POST /api/v1/apps/workflow/completions
```

### 请求

```json
{
  "appId": "2102656885718056961",
  "conversationId": "",
  "stream": true,
  "draft": false,
  "inputParams": [
    {
      "key": "query",
      "type": "String",
      "source": "sys",
      "value": "我儿子每天一回家就玩手机，作业拖到很晚，我一提醒他就很不耐烦，我不知道该怎么办。"
    },
    {
      "key": "user_stage",
      "type": "String",
      "source": "user",
      "value": ""
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---:|---|
| `appId` | 是 | Workflow 应用 ID |
| `conversationId` | 否 | 会话 ID |
| `stream` | 否 | `false`：JSON；`true`：SSE |
| `draft` | 否 | 外部调用固定 `false` |
| `inputParams` | 是 | Workflow 输入参数 |

`inputParams[]`：

| 字段 | 必填 | 说明 |
|---|---:|---|
| `key` | 是 | 参数名，以应用 `inputSchema` 为准 |
| `type` | 是 | 参数类型 |
| `source` | 是 | `sys` / `user` |
| `value` | 是 | 参数值 |

约定：

- `query` 使用 `source=sys`
- Start 节点业务参数使用 `source=user`
- `key` 是工作流变量名，不强制改成驼峰

### 非流式返回

```json
{
  "conversationId": "conv_xxx",
  "taskId": "task_xxx",
  "status": "completed",
  "content": "{\"result\":\"PASS\"}"
}
```

| 字段 | 说明 |
|---|---|
| `conversationId` | 会话 ID |
| `taskId` | Workflow 任务 ID |
| `status` | `in_progress` / `completed` / `failed` / `pause` |
| `content` | Workflow 对外输出 |
| `errorCode` | 失败时返回 |
| `errorMessage` | 失败时返回 |

### SSE

请求设置：

```json
{
  "stream": true
}
```

事件示例：

```text
data: {"conversationId":"conv_xxx","taskId":"task_xxx","status":"in_progress","content":"处理中"}

data: {"conversationId":"conv_xxx","taskId":"task_xxx","status":"completed","content":"处理完成"}
```

SSE 无 `[DONE]`，以业务 `status` 和连接关闭判断结束。

## 5. Workflow 异步调用

### 5.1 启动

```http
POST /api/v1/apps/workflow/async-completions
```

请求体与 Workflow 调用一致，不需要 `stream=true`。

返回：

```json
{
  "requestId": "req_xxx",
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_xxx",
    "conversationId": "conv_xxx",
    "requestId": "req_xxx"
  }
}
```

保存 `taskId`。

### 5.2 查询结果

```http
POST /api/v1/apps/workflow/async-results
```

请求：

```json
{
  "taskId": "task_xxx"
}
```

返回：

```json
{
  "requestId": "req_xxx",
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_xxx",
    "requestId": "req_xxx",
    "conversationId": "conv_xxx",
    "taskStatus": "success",
    "taskExecTime": "1280ms",
    "outputs": [
      {
        "content": "{\"result\":\"PASS\"}",
        "nodeId": "node_end_1",
        "nodeName": "结束",
        "nodeType": "End",
        "nodeStatus": "success"
      }
    ]
  }
}
```

`outputs` 仅返回 Output / End 节点结果。

### 5.3 停止

```http
POST /api/v1/apps/workflow/stop-completions
```

请求：

```json
{
  "taskId": "task_xxx"
}
```

返回：

```json
{
  "requestId": "req_xxx",
  "code": 200,
  "message": "success",
  "data": true
}
```

## 6. 错误返回

API Key 无效：

```json
{
  "requestId": "req_xxx",
  "code": 401,
  "message": "Api key is invalid."
}
```

业务参数错误示例：

```json
{
  "requestId": "req_xxx",
  "code": 400,
  "message": "Required parameters [appId] missing, please check the request parameters."
}
```
