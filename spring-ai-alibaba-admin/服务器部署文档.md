## 3. 后端 systemd 服务

systemd 配置文件：

```text
/etc/systemd/system/saa-admin.service
```

内容：

```ini
[Unit]
Description=SAA Admin Backend
After=network.target

[Service]
Type=simple
WorkingDirectory=/app/saa/backend

ExecStart=/usr/bin/java -Xms1g -Xmx2g -XX:+UseG1GC \
  -jar /app/saa/backend/spring-ai-alibaba-admin-server-start.jar \
  --spring.config.additional-location=file:/app/saa/application-prod.yml

Restart=always
RestartSec=5
SuccessExitStatus=143

[Install]
WantedBy=multi-user.target
```

加载并设置开机启动：

```bash
systemctl daemon-reload
systemctl enable saa-admin
```

启动：

```bash
systemctl start saa-admin
```

重启：

```bash
systemctl restart saa-admin
```

停止：

```bash
systemctl stop saa-admin
```

查看状态：

```bash
systemctl status saa-admin
```

查看实时日志：

```bash
journalctl -u saa-admin -f
```

检查后端端口：

```bash
ss -lntp | grep 18091
```

## 4. Nginx 配置

当前服务器 Nginx 主配置：

```text
/etc/nginx/nginx.conf
```

其中已经存在：

```nginx
include sites/*.conf;
```

因此 SAA 单独增加配置：

```text
/etc/nginx/sites/saa.conf
```

内容：

```nginx
server {
    listen 18090;
    server_name _;

    root /app/saa/frontend/dist;
    index index.html;

    client_max_body_size 500m;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:18091;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }

    location /console/ {
        proxy_pass http://127.0.0.1:18091;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        proxy_buffering off;
        proxy_read_timeout 600s;
    }

    location /oauth2/ {
        proxy_pass http://127.0.0.1:18091;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

检查配置：

```bash
nginx -t
```

重新加载：

```bash
systemctl reload nginx
```

检查前后端端口：

```bash
ss -lntp | grep -E ':18090|:18091'
```

当前端口：

```text
18090 -> Nginx 前端入口
18091 -> Java 后端
```

浏览器访问：

```text
http://服务器IP:18090
```

## 5. 当前启动方式

后端：

```text
systemd
  -> saa-admin.service
  -> Java 17
  -> /app/saa/backend/spring-ai-alibaba-admin-server-start.jar
  -> /app/saa/application-prod.yml
  -> 127.0.0.1:18091
```

前端：

```text
Nginx
  -> /app/saa/frontend/dist
  -> 18090
```

Nginx 将：

```text
/api/*
/console/*
/oauth2/*
```

转发到：

```text
http://127.0.0.1:18091
```
